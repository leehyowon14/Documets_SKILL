# 문서 작성 예시

문맥과 의미를 확인한 뒤 수정 여부를 판단한다. 예시 문구를 모든 문장에 일괄 적용하지 않는다.

## 문체별 예시

같은 내용의 종결 방식을 바꾸더라도 의미와 판단 강도는 유지한다.

| 문체 | 예시 |
| --- | --- |
| 한다체 | 제품의 규모와 반복 작업에 따라 첫 범위를 정한다. 여러 화면에서 반복되는 요소를 먼저 정리하고, 적용 결과를 확인한 뒤 범위를 넓힌다. |
| 합니다체 | 제품의 규모와 반복 작업에 따라 첫 범위를 정합니다. 여러 화면에서 반복되는 요소를 먼저 정리하고, 적용 결과를 확인한 뒤 범위를 넓힙니다. |
| 해요체 | 제품의 규모와 반복 작업에 따라 첫 범위를 정해요. 여러 화면에서 반복되는 요소를 먼저 정리하고, 적용 결과를 확인한 뒤 범위를 넓혀요. |
| 명사형 제목 | 초기 적용 범위 / 반복 요소 정리 / 적용 결과 검토 |

### 문체 보존 예외

| 구분 | 예시 |
| --- | --- |
| 본문 | 사용자는 ‘다음’ 버튼을 눌러 입력 내용을 확인한다. |
| UI 문구 | 입력 내용을 확인해 주세요. |
| 판단 | 본문은 한다체를 유지하고, UI 문구의 합니다체는 그대로 둔다. |

## 교정 유형별 예시

| 유형 | 입력 | 처리 결과 | 판단 이유 |
| --- | --- | --- | --- |
| 명사형 제목 | 사용하는 방법을 찾아봤다 | 사용법 조사 결과 | 제목의 명사형 종결 |
| 제목의 의미 보존 | 성능이 어떻게 달라졌는지 분석했다 | 성능 변화 분석 | 개선이 확인되지 않은 상태에서 개선 효과로 단정하지 않음 |
| 주체와 대상 | 데이터의 정확성이 결과의 신뢰도를 결정한다. | 결과의 신뢰도는 데이터의 정확성이 결정한다. | 승인한 문장 구성 |
| 자연스러운 어순 유지 | 사용자의 숙련도에 따라 작업 시간이 달라진다. | 그대로 유지 | 조건과 변화의 관계가 자연스러움 |
| 연결 관계 | 글자의 위계, 버튼의 동작, 오류 안내, 재사용할 코드와 변경 절차가 서로 연결된다. | 글자의 위계, 버튼의 동작, 오류 안내, 재사용할 코드와 변경 절차는 유기적으로 연결되어 있다. | 관계의 성격을 표현하는 해당 문맥의 예시 |
| 판단 기준과 행동 | 처음 정의할 범위는 제품의 규모와 반복 작업에 맞춘다. | 제품의 규모와 반복 작업에 따라 첫 범위를 정한다. | 기준과 결정의 흐름 |
| 명사 표현 정리 | 강한 경쟁력을 가지고 있다. | 경쟁력이 강하다. | 특성을 자연스러운 형용사로 표현 |
| 이중 피동 | 판단되어진다. | 판단된다. | 의미를 유지하며 이중 피동 정리 |
| 피동 유지 | 요청한 이미지가 생성되었다. | 그대로 유지 | 생성 결과를 설명하는 문장 |
| 변화 표현 유지 | 설정을 조정하면 화면이 밝아지게 된다. | ‘-지게 된다’라는 이유만으로 이중 피동으로 판정하지 않음 | 상태 변화의 의미 |
| 조사 결합 | 실험에 있어서의 제약 | 실험을 수행할 때의 제약 | 조사 결합을 절로 표현 |
| 삽입 설명 | 검토 결과—표본이 적다는 한계가 있지만—는 가설을 지지한다. | 표본이 적다는 한계가 있지만, 검토 결과는 가설을 지지한다. | 명사와 조사를 가르는 삽입 설명 이동 |
| 복수 표현 정리 | 세 개의 항목들을 비교했다. | 세 개의 항목을 비교했다. | 수량이 이미 명시됨 |
| 복수 의미 유지 | 그 아이들이 돌아왔다. | 그대로 유지 | 여러 아이를 지칭하는 의미 보존 |
| 외래어 표기 | 사용자 흐름 | 해당 문맥에서 ‘유저 플로우’ 사용 | 통용되는 외래어 표기 허용 |
| 명칭 소개 | ‘AGI’라고 알려진 범용 인공지능 | 범용 인공지능(AGI) | 명칭 소개를 간결하게 정리 |
| 강조용 따옴표 | 이 기능은 “공동 편집”을 지원한다. | 이 기능은 공동 편집을 지원한다. | 일반적인 기능명에 붙인 강조 제거 |
| 직접 인용 | 연구자는 “추가 검증이 필요하다”고 밝혔다. | 인용문과 따옴표 유지 | 직접 인용의 원문 보존 |

## 잘못된 교정 예시

| 입력 | 금지할 교정 | 이유 |
| --- | --- | --- |
| 인력 전환이 더 큰 병목이 될 수 있다. | 병목은 인력 전환이다. | 비교와 가능성의 의미 소실 |
| 연구 결과는 두 변수의 관련성을 시사한다. | 연구 결과로 두 변수의 관련성이 입증되었다. | 판단 강도 상승 |
| 추가 검증이 필요하다. | 추가 검증을 수행했다. | 필요성을 완료된 사실로 변경 |
| 이 기능은 더 이상 지원하지 않는다. | 이 기능은 이제 지원한다. | 부정과 지원 종료의 의미 소실 |
| 이 솔루션의 가치는 분명하다. | 이 솔루션은 운영 비용을 40% 줄인다. | 근거 없는 수치 추가 |
| 수요가 시장을 떠받치고 있다는 분석이다. | 수요가 시장을 떠받치고 있다. | 출처와 판단 성격을 확인하지 않은 채 단정으로 변경 |

마지막 사례는 앞뒤 문맥에서 출처를 먼저 확인한다. 확인되지 않으면 출처나 작성자의 해석 여부를 확인하고, 확인 전에는 사실 단정으로 바꾸지 않는다.

## 가운뎃점 열거의 교정 예시

| 입력 | 처리 결과 | 조건 |
| --- | --- | --- |
| 대본 버전·문장 ID·주변 문맥을 함께 참조한다. | 대본 버전과 문장 ID, 주변 문맥을 함께 참조한다. | 나열 대상 유지 |
| 글꼴·크기·간격을 조정한다. | 글꼴과 크기, 간격을 조정한다. | 조정 대상 유지 |
| 수집·분석·검증을 수행한다. | 자료를 수집하고 분석한 뒤 검증한다. | 대상이 자료이고 실제로 이 순서가 있는 경우 |
| 수집·분석·검증을 수행한다. | 수집과 분석, 검증을 수행한다. | 순서가 명시되지 않은 경우 |

직접 인용과 고유명사의 표기는 보존한다. 가운뎃점 열거를 정리하면서 출처의 원문이나 명칭을 바꾸지 않는다.
