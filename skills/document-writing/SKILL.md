# 문서 작성 지침

작성 전 아래 규칙을 읽고 초안 작성과 퇴고에 적용한다. 지면·글꼴·페이지 분할은 선택한 문서 템플릿을 따른다. 규칙 자체를 결과물 본문에 삽입하지 않는다. 퇴고할 때는 [교정 예시](references/writing-examples.md)의 해당 유형을 확인한다. 예시는 문맥에 따라 적용하며 일괄 치환 규칙으로 사용하지 않는다.

## 기본 문체

별도 요청이 없으면 본문은 한다체로 작성한다. 사용자가 다른 문체를 지정하면 해당 문체를 일관되게 적용한다. A4와 Go 7 등의 지면 형식은 문체 선택에 영향을 주지 않는다. 작성 전에 [문체별 예시](references/writing-examples.md#문체별-예시)에서 선택한 문체를 확인한다.

소제목과 챕터명은 명사형으로 끝맺는다. 본문 전체를 “검토함”, “확인됨” 등의 명사형 종결로 작성하지 않는다. 직접 인용, 대화 예시, UI 문구는 해당 맥락의 문체를 보존한다. 본문의 종결 방식에 맞추기 위해 이를 일괄적으로 바꾸지 않는다.

| 문체 | 사용 기준 |
| --- | --- |
| 한다체 | 별도 요청이 없는 문서 본문의 기본값 |
| 합니다체 | 사용자가 격식 있는 안내나 설명 문체를 요청한 경우 |
| 해요체 | 사용자가 친근한 안내나 설명 문체를 요청한 경우 |
| 명사형 종결 | 소제목, 챕터명, 표의 짧은 항목, 상태 표시 |

## 제목과 문장 구성

- **명사형 제목:** 소제목과 챕터명은 구체적인 명사 또는 명사구로 끝맺는다. 서술형·질문형과 끝의 마침표는 사용하지 않는다.
- **판단 강도와 의미 보존:** 제목과 본문을 다듬더라도 사실, 인과관계, 시제, 가능성, 의무의 의미를 바꾸지 않는다. “개선될 수 있다”를 “개선된다”로, “검증해야 한다”를 “검증한다”로 바꾸지 않는다. 개선 여부를 확인하기 전에는 “성능 개선 효과” 대신 “성능 변화 분석”을 사용한다.
- “시사한다”를 “입증한다”나 “드러났다”로 강화하지 않는다. 비교와 가능성, 의무, 시제, 부정의 의미를 보존한다. 근거에 없는 수치나 행위 주체, 적용 범위를 추가하지 않는다.
- **주체와 대상:** 행위나 판단의 주체와 대상을 명확하게 표현한다. 조건·원인·변화의 관계와 문맥에 따라 어순을 선택하며, 주체나 대상을 일괄적으로 앞에 배치하지 않는다.
- **불필요한 명사 표현 정리:** 본문에서 동작이나 상태를 명사로 길게 풀어 쓴 표현은 자연스러운 동사·형용사로 정리한다. 예: “강한 경쟁력을 가지고 있다” → “경쟁력이 강하다.” 제목의 명사형 종결과는 구분한다.
- **이중 피동과 행위 주체 정리:** 이중 피동은 의미가 유지되는 범위에서 정리한다. 예: “판단되어진다” → “판단된다.” 능동태로 바꿀 때는 행위 주체가 명확하고 문장의 초점이 유지되는지 확인한다. 결과나 상태를 설명하는 데 자연스러운 피동 표현은 유지한다. 변화나 결과를 나타내는 “-지게 된다”를 일괄적으로 이중 피동으로 취급하지 않는다.

| 변경 전 | 변경 후 |
| --- | --- |
| 사용하는 방법을 찾아봤다 | 사용법 조사 결과 |
| 기존 방식에는 어떤 문제가 있는가? | 기존 방식의 문제점 |
| 시스템이 어떻게 작동하는지 알아본다 | 시스템 작동 원리 |
| 두 가지 방법을 비교해 보았다 | 두 방법의 비교 결과 |
| 이 기술을 도입해야 하는 이유 | 기술 도입의 필요성 |
| 앞으로 무엇을 해야 하는가? | 향후 추진 과제 |
| 조사 결과를 어떻게 활용할 수 있는가? | 조사 결과의 활용 방안 |

문장 구성 예시:

- “데이터의 정확성이 결과의 신뢰도를 결정한다.” → “결과의 신뢰도는 데이터의 정확성이 결정한다.”
- “사용자의 숙련도에 따라 작업 시간이 달라진다.”는 그대로 유지한다. 조건에 따른 변화를 설명하는 자연스러운 어순을 기계적으로 바꾸지 않는다.
- “글자의 위계, 버튼의 동작, 오류 안내, 재사용할 코드와 변경 절차가 서로 연결된다.” → “글자의 위계, 버튼의 동작, 오류 안내, 재사용할 코드와 변경 절차는 유기적으로 연결되어 있다.”
- “처음 정의할 범위는 제품의 규모와 반복 작업에 맞춘다.” → “제품의 규모와 반복 작업에 따라 첫 범위를 정한다.”

## 조사·삽입 설명·복수 표현

- **조사 결합의 정리:** “-으로부터의”, “-에 있어서의”처럼 조사가 겹친 표현은 의미에 맞는 조사나 절로 풀어 쓴다. “의” 자체를 금지하지 않는다. 예: “관리자로부터의 승인” → “관리자의 승인”, “실험에 있어서의 제약” → “실험을 수행할 때의 제약”.
- **삽입 설명의 위치 조정:** 괄호나 줄표로 넣은 설명이 명사와 조사, 주어와 서술어를 갈라놓으면 위치를 옮기거나 별도 문장으로 분리한다. 예: “검토 결과—표본이 적다는 한계가 있지만—는 가설을 지지한다.” → “표본이 적다는 한계가 있지만, 검토 결과는 가설을 지지한다.”
- **복수 의미의 보존:** “-들”을 기계적으로 붙이거나 삭제하지 않는다. 수량이 이미 드러나는 표현은 중복을 줄이되, 여러 개체를 가리키는 의미가 사라지지 않도록 한다. 예: “세 개의 항목들을 비교했다.” → “세 개의 항목을 비교했다.” 반면 “그 아이들이 돌아왔다.”의 “들”은 유지한다.

## 용어와 영문 병기

- **용어의 일관성:** 같은 개념은 같은 용어로 표현한다. 해당 분야에서 통용되는 영어 용어와 한글 외래어 표기를 허용하며, 부자연스러운 한국어 번역을 강제하지 않는다. 예를 들어 “사용자 흐름”보다 “유저 플로우”가 자연스러운 문맥에서는 “유저 플로우”를 사용한다. 문서 안에서는 선택한 표기를 일관되게 유지한다. 고유명사는 억지로 번역하지 않는다.
- **영문 병기의 일관성:** 영문 병기는 필요한 경우 첫 등장에 제공하고, 이후에는 정한 표기를 일관되게 사용한다.

- **명칭 소개:** 약어나 명칭은 필요한 설명과 함께 간결하게 소개한다. 명칭의 통용 여부나 사용 맥락 자체를 설명하는 표현은 유지한다. 이후에는 영어 원어, 한글 외래어, 한국어 번역어 중 선택한 표기를 일관되게 사용한다.

## 줄글과 강조 표현

- **줄글 우선:** 본문은 문장과 문단이 자연스럽게 이어지는 줄글로 작성한다. 각 문단은 하나의 주제를 중심으로 구성한다.
- **목록 최소화:** Bullet point와 번호를 이용한 나열은 가급적 피한다. 절차의 순서나 개별 항목의 구분이 이해에 필요한 경우에만 허용한다.
- **시각적 강조 지양:** 본문에서 굵은 글씨 등 강조 서식을 피한다. 구체적인 설명과 근거로 의미를 전달한다.
- **강조용 따옴표의 절제:** 따옴표는 직접 인용이나 용어를 특별한 의미로 사용하는 경우에 쓴다. 일반 개념이나 중요 단어를 강조하기 위한 반복 사용은 피한다. 직접 인용을 표시하는 따옴표는 유지한다.
- **금지 표현:** “단순”, “단순히”, “핵심” 및 이 단어를 포함한 표현을 사용하지 않는다.
- **대비를 통한 강조 금지:** “-가 아니라 -다”, “-이 아닌 -이다”, “단순 -가 아니다”, “단순 -가 아니라”처럼 부정 후 재정의하는 강조 구문을 사용하지 않는다. 전달하려는 내용을 직접 서술한다.
- **강조 문구 최소화:** “가장 중요한 점은 다음과 같다.”와 같은 표현도 필요한 경우에만 사용한다. 가능하면 설명할 내용을 바로 제시한다.

| 변경 전 | 변경 후 |
| --- | --- |
| 이 도구는 단순한 편집기가 아니라 협업 플랫폼이다. | 이 도구는 공동 편집과 검토 기능을 제공하는 협업 플랫폼이다. |
| 핵심은 이거다. | 가장 중요한 점은 다음과 같다. |
| 핵심은 데이터의 정확성이다. | 결과의 신뢰도는 데이터의 정확성이 결정한다. |
| 단순히 설정을 변경하면 된다. | 설정을 변경하면 적용된다. |
| 핵심 기능 | 주요 기능 |

## Abstract와 요약

- 문서 전체의 요약은 Abstract에서 제공한다.
- Abstract 이후에는 챕터별 요약, 중간 정리, 별도의 전체 요약을 추가하지 않는다. 절의 끝에서 앞선 내용을 반복하는 문단도 작성하지 않는다.
- 결론이 필요한 경우에는 앞선 내용을 재요약하지 않고, 논의에서 도출되는 시사점·제언·후속 과제를 기술한다.

## APA 인용

- 본문 인용과 참고문헌은 별도 판본 지정이 없으면 **APA 제7판**으로 통일한다.
- 다른 자료에서 가져온 주장·수치·해석에는 출처를 표시하고, 직접 인용과 간접 인용을 구분한다.
- 본문 인용에는 저자와 출판 연도를 표기한다. 직접 인용에는 페이지 번호를 추가하며, 페이지가 없는 자료는 문단 번호 등 위치 정보를 사용한다.
- 본문 인용과 참고문헌 목록을 서로 일치시킨다. 저자·날짜·제목·출판 정보·DOI 또는 URL은 원자료를 확인하여 기재하고, 확인하지 못한 정보를 임의로 만들지 않는다.

- 다른 사람의 분석이나 평가를 전달하는 문장은 판단 주체와 출처를 확인한다. 출처가 없으면 작성자의 해석인지 확인하고, 확인된 성격에 맞춰 기술한다. 출처 표시만 지운 뒤 사실로 단정하거나 판단 주체를 임의로 만들어 넣지 않는다.

## 면책성 문구

- Disclaimer는 문서의 목적과 독자의 판단에 필요한 경우에만 포함한다. 관행적인 주의 문구, 포괄적인 책임 회피 문구, 같은 경고의 반복은 피한다.
- 자료의 한계·불확실성·적용 조건이 결과 해석에 영향을 준다면 해당 내용 가까이에 짧고 구체적으로 기술한다.
- 면책성 문구를 줄이더라도 실제 한계나 확인되지 않은 사실은 숨기지 않는다.

## 최종 검수

- 본문이 기본 한다체 또는 사용자가 지정한 문체로 일관적인지 확인한다. 직접 인용, 대화 예시, UI 문구의 문체는 별도로 보존한다.

- 제목이 명사형으로 끝나는지, 문장 속 주체와 대상의 관계가 명확한지 확인한다.
- 문장을 다듬으며 판단 강도나 의미가 달라지지 않았는지, 용어와 영문 병기가 일관적인지 확인한다.
- 피동을 능동으로 바꾼 문장의 행위 주체와 초점, 강조용 따옴표의 필요성, 분석과 평가의 출처를 확인한다.
- 목록의 필요성을 판단하고, 줄글로 충분한 부분은 문단으로 바꾼다.
- 금지 표현, 부정 후 재정의하는 강조 구문, 본문의 강조 서식을 확인한다.
- Abstract 이후의 요약 반복을 제거한다.
- APA 인용과 참고문헌의 대응 및 실제 출처 정보를 확인한다.
- 면책성 문구의 필요성을 확인하고, 해석에 필요한 한계는 구체적으로 남긴다.
