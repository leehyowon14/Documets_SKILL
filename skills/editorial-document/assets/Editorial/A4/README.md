# Clear A4

문서 작성 시 [공통 작성 규칙](../WRITING_RULES.md)을 반드시 적용합니다. 템플릿을 별도 폴더로 복사할 때는 작성 규칙도 함께 보관합니다.

전달·태블릿 전자 뷰어용과 종이 인쇄용을 별도 HTML·PDF로 제공하는 흑백 모노톤 템플릿. 표지에는 제목·부제와 작성 정보를, 본문에는 제목과 내용을 배치합니다.

## 파일

- `example.html`: 팀 표지, 목차와 초록, 줄글, 항목 번호, 표·그래프, 목록·일정, 이미지, 부록, 참고문헌의 9쪽 예시
- `starter.html`: 이름·학번이 있는 개인 제출용 2쪽 시작 파일
- `starter-general.html`: 이름·학번·수업명을 제외한 비제출용 2쪽 시작 파일
- `example-print.html`: KoPub 바탕 인쇄용 전체 예시 9쪽
- `starter-print.html`, `starter-general-print.html`: 인쇄용 제출·비제출 시작 파일
- `editorial.css`: Pretendard 열람용 기본 스타일
- `print.css`: KoPub 인쇄용 전용 스타일 (미리보기에도 적용)
- `editorial.js`: 페이지 번호·전체 쪽수 계산, 넘침 경고, 인쇄 버튼
- `fonts/PretendardVariable.ttf`: 함께 제공하는 Pretendard 원본 글꼴
- `fonts/LICENSE.txt`: Pretendard 공식 SIL Open Font License

HTML, CSS, JS, `fonts` 폴더를 함께 복사합니다. 외부 네트워크나 별도 빌드는 필요하지 않습니다.

## 표지와 페이지 정보

| 위치 | 표지 | 본문 |
| --- | --- | --- |
| 좌측 상단 | 영문 문서 타입 (`RESEARCH REPORT`) | 문서 제목 |
| 주요 내용 | 제목, 부제, 출간일, 작성 주체, 선택 수업명 | 장 제목과 본문 |
| 좌측 하단 | 팀명 또는 개인 문서의 프로젝트명 | 영문 문서 타입 |
| 우측 하단 | 현재 쪽 / 전체 쪽 | 현재 쪽 / 전체 쪽 |

문서 버전, 표지 설명문, 캡슐 문구, 중복 문서 타입과 쪽수 필드는 사용하지 않습니다. 수업명은 필요 없으면 `.meta-item` 전체를 삭제합니다. 목차 아래에는 초록과 쉼표로 구분한 키워드를 배치합니다. 목차 자체에는 제목과 항목·쪽번호만 둡니다. 각 장에는 장 제목 외의 장식용 부제나 도입 문구를 붙이지 않습니다.

팀 표지는 `example.html`처럼 팀명과 팀원 필드를 분리하고, 팀장 이름 뒤에 `*`를 붙이고 이름은 쉼표로 구분합니다. 기호 설명은 표지에 반복하지 않습니다. 개인 제출용 표지는 `starter.html`처럼 이름과 학번을 표시합니다. 비제출용은 `starter-general.html`을 사용하며 이름·학번을 기재하지 않습니다. 개인 표지의 좌측 하단에는 이름을 반복하지 않고 프로젝트명 등을 씁니다. 본문은 한국어 창작 더미 문장과 Lorem ipsum을 섞고, 이름·날짜·제목은 자리표시자로 표시합니다. 사용 설명은 이 README에만 둡니다.

페이지 수는 표지를 포함한 `.page` 개수입니다. `data-page-count`, `data-page-number`는 로드 시 자동 계산되며 실제 PDF 엔진의 물리적 쪽수를 읽는 기능은 아닙니다. 목차 번호와 제목, 머리말·꼬리말은 직접 수정합니다. JavaScript를 끄면 정적 번호만 남으므로 브라우저 인쇄 메뉴를 사용하고 수동으로 번호를 맞춥니다.

## 글꼴과 R값

전달·태블릿 열람용은 Pretendard를 사용하며 굵기는 아래 세 가지로 제한합니다. 코드 예시도 같은 글꼴을 사용합니다.

| 굵기 | CSS 값 | 용도 |
| --- | --- | --- |
| Light | 300 | 표지 부제, 보조 정보, 캡션, 각주, 꼬리말 |
| Regular | 400 | 본문, 목록, 일반 값 |
| Semibold | 600 | 제목, 소제목, 표 머리글, 강조 |

인쇄용은 KoPub 바탕 2.0 Light(본문), Medium(제목), Bold(강조)를 사용합니다. `fonts/KoPub-LICENSE.pdf`의 공식 라이선스와 원본 TTF 파일을 함께 전달합니다. 두 버전 모두 HTML 미리보기와 PDF에 같은 폰트를 사용하며, 인쇄 메뉴를 실행했다고 열람용이 인쇄용 서체로 자동 전환되지는 않습니다.

`@font-face`로 로컬 파일을 연결합니다. 가변 원본 파일을 포함하지만 선언과 사용 굵기는 300·400·600뿐이며 합성 굵기는 비활성화합니다.

표 외곽 네 모서리, 카드, 이미지, 코드 블록, 안내 상자에는 공통 `--radius: 4mm`를 적용합니다. 막대 그래프의 끝은 막대 형태에 맞게 둥글게 처리하고, 본문 인용은 모서리 없이 세로선만 사용합니다.

## 본문과 컴포넌트

| 쪽 | 내용 | 주요 클래스 |
| --- | --- | --- |
| 1 | 팀 표지 | `cover`, `cover-meta`, `meta-item` |
| 2 | 목차와 초록 | `toc-page`, `toc` |
| 3 | 연속 문단, 소제목, 인용, 각주 | `prose-body`, `prose-quote`, `prose-footnote` |
| 4 | 번호 체계와 단계별 들여쓰기 | `outline-body`, `outline-section`, `outline-list` |
| 5 | 목록, 비교 표, 막대 그래프, 인용 | `table`, `bars`, `blockquote` |
| 6 | 단계, 일정, 체크리스트, 안내 | `steps`, `timeline`, `checklist`, `note` |
| 7 | 가로 이미지, 2열 이미지, 캡션 | `figure`, `figure-grid` |
| 8 | 용어, 코드, 표 | `definition`, `code` |
| 9 | 독립 참고문헌 | `references-page`, `references` |

### 줄글

`.prose-body` 안에 `<p>`로 작성합니다. 본문은 11pt Regular, 행간 1.8, 문단 간격 2mm입니다. 양쪽 정렬을 사용합니다. 문장마다 `<br>`를 넣지 않고 자동 줄바꿈에 맡깁니다. 문단 첫 줄은 1em(한 글자) 들여씁니다. 인용문은 첫 줄을 들여쓰지 않습니다. `<strong>`으로 강조하고 `.prose-quote`로 인용합니다. 각주는 `<sup>`의 링크와 고유한 각주 `id`를 연결하며 페이지 하단 25mm 위치에 고정합니다. `.prose-page`는 각주 위 본문 공간을 예약합니다. 각주가 여러 줄로 늘어나면 본문과 겹치지 않는지 확인합니다.

### 들여쓰기

| 단계 | 번호 예 | 왼쪽 위치 | 구조 |
| --- | --- | --- | --- |
| 장 | Ⅱ. | 0mm | 페이지 `h2` |
| 절 | 1. | 2.5mm | `.outline-section` 안의 `h3` |
| 항 | 가. | 5mm | 중첩 `.outline-section` 안의 `h4` |
| 항 아래 목록 | 1) / 2) | 부모 기준 추가 6mm | `.outline-list` |

장·절·항은 `Ⅰ. → 1. → 가. → 1)` 체계로 구성합니다. `.outline-section`마다 `--indent-step: 2.5mm`를 적용하고 본문 첫 줄은 추가로 1em 들여씁니다. 항목 번호는 직접 수정하며, `.outline-list`의 `1)` 번호는 CSS 카운터로 자동 표시합니다. 긴 목록의 두 번째 줄은 첫 줄 본문에 맞춰집니다. 문서·기관별 지정 양식이 있다면 해당 번호 체계로 수정합니다.

### 이미지

7쪽의 `.figure`와 `.figure-grid`를 복사합니다. `images/landscape.svg`(16:9), `images/thumbnail.svg`(4:3)는 로컬 더미 이미지입니다. `img`의 `src`를 실제 파일 경로로 바꾸고 `alt`도 해당 이미지 설명으로 바꿉니다. `figcaption`에는 그림 번호·제목·출처를 넣습니다.

가로형은 16:9, 2열형은 4:3으로 표시하며 `object-fit: cover`로 채웁니다. 원본 전체를 보여야 하는 도표·스크린샷은 `object-fit: contain`을 적용하거나 `aspect-ratio: auto`로 변경합니다. 이미지는 HTML과 함께 전달해야 합니다.

### 그 외 요소

표 제목에는 `scope="col"`, 행 제목에는 `scope="row"`를 유지합니다. 그래프의 `--value:85%`와 표시값을 함께 수정합니다. 체크리스트의 `done` 클래스에 따른 완료 여부는 정적 표시입니다. 상태 배지는 사용하지 않습니다.

## 페이지 추가와 PDF 출력

1. 본문 `.page` 전체를 복제하고 고유한 `id`와 내용을 수정합니다.
2. 한 쪽 분량에 맞게 문단을 직접 나눕니다. 자동 문단·각주 조판 템플릿이 아닙니다.
3. 페이지 번호, 목차, 머리말과 꼬리말을 확인합니다.
4. `인쇄 / PDF 저장` 또는 브라우저 인쇄 메뉴를 실행합니다.

출력 설정: **A4 세로 · 배율 100% · 여백 없음 · 브라우저 머리글/바닥글 끄기 · 배경 그래픽 켜기**.

화면에서 내용 높이를 넘으면 외곽선과 경고가 표시되고 템플릿 인쇄 버튼이 실행되지 않습니다. 브라우저 자체 인쇄 단축키까지 막지는 않습니다. 긴 제목, 긴 URL, 중첩 목록, 표지 삭제·페이지 추가 후 실제 인쇄 미리보기의 잘림과 쪽수를 확인하세요.

## 검증

- WeasyPrint 70 로컬 렌더링: 예시 9쪽, 제출용·비제출용 시작 파일 각각 2쪽 A4 확인.
- `output/pdf/editorial-a4-viewer.pdf`: A4 전달·태블릿 열람용 9쪽 (Pretendard).
- `output/pdf/editorial-a4-print.pdf`: A4 종이 인쇄용 9쪽 (KoPub 바탕 2.0).
- `output/pdf/editorial-reference.pdf`: 기존 링크 호환용 열람용 PDF 복사본.
- PDF는 WeasyPrint 참고 출력이며 브라우저 인쇄 결과는 아닙니다.
- 인앱 브라우저의 로컬 파일 접근 정책으로 실제 브라우저 인쇄 대화상자는 미검증입니다.
- `node Documents/Editorial/A4/tests/pagination.cjs`: 0/1/5/12쪽 번호 계산, 넘침 경고, 인쇄 호출 차단 로직 검증. DOM 모형 검사로 실제 조판 검증을 대신하지 않습니다.
- 예시 본문은 내용 전달이 아닌 조판 확인용 한국어·영문 더미이며, 수치도 더미 데이터입니다.

표지 제목·부제는 왼쪽 페이지 여백에 맞춰 좌측 정렬하고, 제목 블록의 세로 위치는 표지 중앙 영역에 유지합니다. 제목은 32pt Semibold이며, 작성 정보 카드는 페이지 하단 29mm에 고정합니다. 제목이 길어지거나 정보 행을 늘릴 때 실제 PDF에서 겹침을 확인하세요.
