# 문서 작성 규칙

이 규칙은 Editorial 템플릿으로 문서를 작성할 때마다 적용한다. 템플릿에 구현된 글꼴·정렬·간격·위치·컴포넌트 형태는 해당 템플릿을 따르며, 여기에는 작성 시 판단해야 하는 규칙만 기록한다.

- **용도에 맞는 버전 선택:** A4 전자 열람용, A4 인쇄용, Go 7용을 구분한다.
- **작성자 정보 선택:** 팀 문서는 팀명·팀원을 표시하고, 개인 제출용은 이름·학번을 표시한다. 비제출용은 이름·학번을 제외한다.
- **팀원 표기:** 이름은 쉼표로 구분하고 팀장에게 `*`를 붙인다. 별도의 의미 설명은 넣지 않는다.
- **선택 정보 처리:** 수업명 등 해당 문서에 필요하지 않은 항목은 빈칸으로 남기지 말고 삭제한다.
- **불필요한 설명 금지:** 표지·목차·절 제목에 소개 문장, 부제, 사용 안내를 임의로 덧붙이지 않는다. 표지의 문서 부제는 유지한다.
- **장식 요소 추가 금지:** 캡슐, 상태 배지, 장식용 문구를 새로 넣지 않는다.
- **정보 중복 금지:** 문서 타입이나 쪽수처럼 이미 표시한 정보를 다른 영역에 반복하지 않는다.
- **실제 내용으로 교체:** 더미 텍스트·이미지·자리표시자·예시 출처를 교체하고, 사용하지 않는 예시 컴포넌트는 삭제한다.
- **분량에 따른 재조정:** 실제 내용을 넣은 뒤 본문 밀도와 페이지 나눔을 점검한다. 억지로 한 페이지에 넣기 위해 글자를 과도하게 줄이지 않는다.
- **최종 PDF 검수:** 각 출력 버전에서 글꼴, 줄바꿈, 잘림·겹침, 목차 쪽수와 전체 페이지 수를 확인한다.
- **문서 버저닝:** 문서 버저닝은 파일 이름으로 하며, 문서에는 별도로 표기하지 아니한다.
