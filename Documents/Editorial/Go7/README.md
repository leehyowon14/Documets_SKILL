# BOOX Go 7 문서 템플릿

문서 작성 시 [공통 작성 규칙](../WRITING_RULES.md)을 반드시 적용합니다. 템플릿을 별도 폴더로 복사할 때는 작성 규칙도 함께 보관합니다.

A4 원본을 유지한 별도 소형 화면용 템플릿입니다. KoPub 바탕 2.0 Light / Medium / Bold, 흑백, 더미 텍스트, 표지 중앙 영역 좌측 정렬을 유지합니다.

## 크기 기준

[BOOX 공식 사양](https://booxsupport.zendesk.com/hc/en-us/articles/360027768131-What-are-the-specifications-of-BOOX-devices)의 Go 7 화면은 1680 × 1264px, 300ppi입니다. 세로 방향으로 환산하면 **107.018667 × 142.24mm**, 비율은 **1264:1680**입니다. 기기 외형 크기가 아니라 화면 해상도와 픽셀 밀도에서 계산한 지면 크기입니다.

PDF는 벡터 문서이므로 고정 픽셀 해상도는 없으며, 300dpi로 래스터화하면 약 1264 × 1680px가 됩니다.

## 파일

- `example.html`: 팀 표지와 컴포넌트 전체 예시 13쪽
- `starter.html`: 이름·학번을 포함한 개인 제출용 2쪽
- `starter-general.html`: 이름·학번이 없는 비제출용 2쪽
- `editorial.css`, `editorial.js`: 지면과 페이지 번호·인쇄 기능
- `fonts/`, `images/`: 오프라인 글꼴과 더미 이미지
- 프로젝트 루트 `output/pdf/editorial-go7-reference.pdf`: 검증한 참고 PDF

이 폴더 전체를 복사하면 A4 폴더 없이 독립적으로 사용할 수 있습니다. 기존 A4 템플릿 파일은 변경하지 않았습니다.

## 소형 화면 조정

- 본문 9pt Light, 행간 1.5, 문단 사이 간격 0.5mm, 첫 줄 1em 들여쓰기. 줄글은 양쪽 정렬을 기본으로 하고 문단 마지막 줄은 좌측 정렬.
- 좌우 여백 8.5mm, 위 여백 8mm, 제목 14.4pt, 표지 제목 23.4pt. 장 번호는 Light, 장 제목은 Medium로 구분.
- 목차 2쪽 / 초록·키워드 3쪽으로 분리.
- 표는 2열. 열이 많으면 표를 나누거나 항목·값 형태로 변경.
- 한 쪽에 들어가는 문단과 컴포넌트 수를 줄여 재배치. A4 전체를 축소한 결과가 아님.
- 10쪽 가로 이미지, 11쪽 두 이미지는 세로로 쌓음. 11쪽 이미지 높이 37mm, `object-fit: cover` 적용. 원본 전체가 필요한 도표는 `contain`으로 수정.
- 각주는 하단 14mm, 작성 정보는 하단 17mm에 고정. 표지 작성 정보는 배경 박스 대신 얇은 구분선으로 분리.
- 참고문헌은 13쪽 독립 파트.
- 목차는 반복 가로선을 제거하고 번호·제목·쪽수의 정렬로 구분. 단계 항목도 배경 카드 대신 선과 여백으로 구분.
- 표의 셀 안쪽 여백을 넓히고, 인용문은 세로선과 Regular 본문으로 표시.

번호 체계, 팀·개인 표지 규칙과 컴포넌트 사용법은 [A4 안내](../A4/README.md)를 참고하되, 용지 크기와 글자 크기는 이 문서를 따릅니다. 자동 본문 페이지 나눔은 제공하지 않으며 `.page` 단위로 내용을 나눕니다.

## HTML → PDF

브라우저에서 HTML을 열고 인쇄/PDF 저장을 선택합니다. **배율 100%, 여백 없음, 브라우저 머리글·바닥글 끄기, 배경 그래픽 켜기**를 사용합니다. A4로 설정하면 안 됩니다.

브라우저가 CSS `@page size`를 반영하는지 미리보기에서 확인하세요. 반영하지 않는 인쇄 경로에서는 사용자 정의 용지를 **107.02 × 142.24mm**로 설정합니다. 브라우저·운영체제에 따라 사용자 정의 크기 지원이 다르므로 생성한 PDF의 페이지 크기를 확인해야 합니다.

기기에서는 세로 방향으로 페이지 전체가 보이게 엽니다. 도구 모음·읽기 여백·자동 자르기가 있으면 실제 표시 영역과 글자 크기가 달라질 수 있습니다.

## 검증 범위

- WeasyPrint 70으로 예시 13쪽, 두 시작 파일 각각 2쪽 렌더링.
- PDF 페이지 크기 107.018667 × 142.24mm 확인.
- 전체 예시를 이미지로 확인하고 목차 넘침과 세로 이미지 누락을 수정한 뒤 재확인.
- 페이지 번호·총 쪽수·로컬 이미지와 스타일 경로, JavaScript 구문 검사 통과.
- 실제 BOOX 기기 및 브라우저 인쇄 대화상자는 미검증. 참고 PDF는 WeasyPrint 출력.

## Go 7 글꼴

Go 7에는 [눈누에서 지정한 KoPub 바탕 2.0](https://noonnu.cc/font_page/1626)을 적용합니다. A4 전달·태블릿 열람용은 Pretendard, A4 종이 인쇄용은 KoPub 바탕을 사용하며 각각 별도 파일입니다.

- Light(300): 본문과 보조 정보
- Medium(500): 표지·장·절 제목
- Bold(700): 강조와 키워드 라벨

[한국출판인회의 공식 KoPub 2.0 배포 페이지](https://www.kopus.org/biz-electronic-font2-2/)의 TTF 파일을 변환·수정 없이 사용합니다. `fonts/KoPub Batang Light.ttf`, `KoPub Batang Medium.ttf`, `KoPub Batang Bold.ttf`와 `fonts/KoPub-LICENSE.pdf`를 함께 전달하세요. 기존 Pretendard 파일은 Go 7 폴더에서 제거했습니다.

공식 안내는 이용정보 등록과 서버·서비스 탑재 시 별도 승인 조건을 안내합니다. 이 결과물은 로컬 HTML/PDF 템플릿이며 서버에 게시하지 않았습니다. 배포·서비스 탑재 시 동봉한 공식 라이선스와 배포처 안내를 확인하세요.

PDF의 13쪽과 포함된 글꼴 목록을 검사하여 KoPub Batang Light·Medium·Bold만 임베딩되는 것을 확인했습니다. 코드에도 같은 글꼴을 적용하고 체크 표시는 CSS 선으로 그립니다. 화면 크기는 기존 값을 유지했습니다.

Go 7 예시는 본문 9pt를 유지하며 더미 문단·표 행·일정·참고문헌을 늘렸습니다. 제목과 문단 사이의 과도한 간격을 줄여 실제 본문이 채워진 밀도를 확인할 수 있습니다.

본문과 일부 표·목록에 한국어 창작 더미 문장과 Lorem ipsum을 함께 사용합니다. 한국어 문장도 실제 보고서 내용이 아닌 글꼴·줄바꿈 확인용 예시입니다.

본문 9pt에 맞춰 전체 글자 크기를 기존의 90%로 조정했습니다. 본문 소제목은 9.45pt, 표·목록은 8.1pt, 캡션은 6.3pt, 각주·쪽수는 5.85pt입니다. 본문 행간은 1.5배, 문단 사이 간격은 0.5mm입니다. 줄글 예시는 연속 문단을 추가해 읽기 밀도를 확인할 수 있도록 구성했습니다.
